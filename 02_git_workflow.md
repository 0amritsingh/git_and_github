# Git Workflow and Basic Commands
1. To make a repo
```bash
git init
```
2. To check status of repo
```bash
git status
```
3. To track or add files to staging area 
```bash
# this will add only one file
git add filename.extention

# this will add all files in the repo
git add .
```
4. commiting changes
```bash
git commit -m "commit massege"
```
5. To restore the code that we changes up until last commit
```bash
git restore filename.extention
```
6. To view commiting history
```bash
git log
```
